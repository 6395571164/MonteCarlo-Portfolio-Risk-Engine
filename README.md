# Monte Carlo Portfolio Risk Engine

## Overview

This project implements a Monte Carlo based portfolio risk engine using historical market data from 15 large-cap Indian equities.

The model estimates portfolio risk through:

- Multivariate covariance estimation
- Monte Carlo simulation
- Cholesky decomposition
- Value-at-Risk (VaR)
- Expected Shortfall (ES)
- Correlation stress testing
- Rolling VaR analysis

---

## Methodology

1. Download historical adjusted closing prices
2. Compute logarithmic returns
3. Estimate mean return vector and covariance matrix
4. Generate correlated return scenarios
5. Simulate portfolio losses
6. Calculate VaR and ES
7. Perform correlation stress testing
